Research

Coaching the Coach+self-improving agents

Does a self-improving coach agent (HyperAgents) train better ARC-AGI-2 solvers? No, and thinking longer beats it.
  • A meta agent rewrites a puzzle-solving agent's code, and is also allowed to rewrite its own. We froze the self-improved coaches and had each train a fresh player on new practice puzzles.
  • On a held-out exam, coached players scored about the same as an uncoached one (29.3%). Raising the model's reasoning effort one notch (41.1%) beat every form of coaching.
  • Interactive explorer: try the puzzles, replay every exam answer, read every coaching session and code change.

ShiftHunt+agent eval · interp

Can an AI agent audit a probe for spurious cues with sparse autoencoders, the step SHIFT leaves to a human?
  • Agent gets four linear probes on Gemma-2-2B and a Gemma Scope SAE. Some probes secretly key on a non-topic cue (British spelling, a greeting line). It has to name the cue and pick ≤16 SAE latents whose ablation removes it.
  • Hard subtasks (error-term traps, two-part cues) break the SHIFT recipe agents rediscovered on v1. Every scripted shortcut scores 0 on the trap slot.
  • Red-teamed with ~150 attack submissions, hidden answers re-randomized per run. A cross-model follow-up audits my own earlier numbers.

τ-forge++8.1 pass@1

RL environment and training loop that teaches a 4B model agentic tool use from synthetic conversations alone.
  • LoRA GRPO on Qwen3-4B-Instruct for multi-turn customer-service tool use. τ²-bench retail pass@1 53.1% → 61.2% (95% CI +2.9 to +13.4), pass^4 28.9% → 36.8%.
  • Trained only on programmatically generated, tool-verified synthetic tasks with a scripted customer: no LLM in the training loop, so rollouts are cheap and reproducible.
  • All 114 real benchmark tasks held out of generation and checkpoint selection; one eval on one checkpoint.
